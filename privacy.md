# Privacy Policy - Mert Stream Clipper

Last updated: 10 November 2026

Mert Stream Clipper is a private tool used only by its owner. It does not collect data from any other person.

What the tool processes: When the owner connects his or her own TikTok account, TikTok provides an access token, a refresh token and the account's open ID, together with basic profile information (user.info.basic). The tool uses these only to upload video drafts to that same account (video.upload).

Where data is stored: The tokens are stored locally, on the owner's own computer, in a file that is not shared or uploaded anywhere. The tool has no server, no database and no analytics.

Sharing: No data is sold, shared with third parties or used for advertising. Data is sent only to TikTok, to carry out the uploads the owner starts.

Retention and deletion: The owner can delete the local token file at any time and can revoke the tool's access in the TikTok app under the account's security and permission settings. Revoking access ends all further processing.

Children: The tool is not directed at children and has no users other than its owner.

Questions can be sent by opening an issue in this GitHub repository.
