# Mert Stream Clipper

Mert Stream Clipper is a small personal desktop tool. It helps its owner prepare short vertical video clips and upload them as drafts to the owner's own TikTok account using TikTok Login Kit and the Content Posting API (Upload to TikTok). The owner reviews and publishes every draft manually in the TikTok app.

The tool is not offered to the public and does not process accounts or data of any other users.
